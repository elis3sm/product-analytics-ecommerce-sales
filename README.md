# E-commerce Sales Analysis based on Amazon India

**Продуктовый анализ продаж интернет-магазина на Amazon India: поиск точек роста выручки, оценка структуры заказов, сезонности, возвратов и B2B-сегмента, а также построение простой системы алертов для мониторинга выручки.**

---

## О проекте

Цель – на основе данных о заказах ответить на вопросы, которые обычно задаёт продуктовая команда e-commerce:

- На чём держится выручка и где риск концентрации?
- Как ведёт себя средний чек и что на него влияет?
- Есть ли сезонность и аномалии, которые нужно мониторить?
- Где теряются деньги – отмены, возвраты, логистика?

Каждый раздел построен по циклу: **гипотеза - проверка - вывод – рекомендация**.

---

## Данные

- **Источник:** [Amazon Sale Report – Kaggle](https://www.kaggle.com/datasets/thedevastator/unlock-profits-with-e-commerce-sales-data)
- **Объём:** ~129 000 заказов, 24 колонки
- **Период:** март – июнь 2022
- **Гранулярность:** одна строка = один товар в заказе

> Файл с данными можно скачать с Kaggle по ссылке выше. После скачивания положите его в папку `data/`

---

## Ключевые инсайты

| Область | Инсайт |
|---|---|
| **Выручка** | Топ-3 категории (Set, Kurta, Western Dress) дают **91.2%** всей выручки |
| **Структура заказов** | **97%** заказов – с 1 товаром, средний чек **695 INR** |
| **Отмены** | **14.2%** заказов отменены |
| **Возвраты** | **1.6%** в среднем, но **5 городов со 100% возвратов** |
| **Сезонность** | Пик – апрель 2022 (26.2 млн INR), к июню спад на **~21%** |

---

## Методы

- KPI dashboard: GMV, AOV, доля B2B, топ-категории/города
- Анализ распределений и корреляций
- Сравнение групп с оценкой размера эффекта 
- Временные ряды: сезонность, разрезы по дням недели
- Детекция аномалий
